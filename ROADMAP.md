# Roadmap

This is a small, intention-level roadmap rather than a promise of delivery dates.

- Broaden RAW format and camera compatibility after the native dependency/license path is settled.
- Investigate a safe Linear DNG workflow.
- Improve large-sheet performance and memory diagnostics.
- Add explicit color-management support beyond the current sRGB working path.
- Extend sheet workflows while preserving project schema compatibility.
